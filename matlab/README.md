
# MATLAB Image Processing

This folder contains MATLAB scripts developed for image processing and game-board recognition in the SCARA Robotic Arm Based Tic-Tac-Toe project.

## Purpose

- Process images captured using the ESP32-CAM.
- Convert and handle RGB565 image data.
- Analyze the 5×5 game board.
- Identify and classify the colours of individual board cells.

## Technologies Used

- MATLAB
- Image Processing
- RGB565 Image Format
